### 버그 수정
- 반응형→적응형 스킨 전환 시 프론트 오류 수정 (#17966)
  - 반응형 스킨 사용 상점에서 적응형 모바일/PC 스킨을 사용스킨으로 적용하면 반대쪽 사용스킨이 비워져 프론트 전 페이지에 오류 화면이 노출되던 문제를 수정했습니다.
- 카카오페이 결제 처리 안정성 개선 (#18142)
  - 카카오페이 결제 후 주문 저장이 늦어지는 경우에도 결제가 유지되고 주문이 정상 완료되도록 개선됐어요.
  - 결제 직후 주문 확인이 늦어지면 주문내역에서 확인하도록 안내해요.
- 카카오페이 결제 취소 시 주문 상태 처리 개선 (#18154)
  - 카카오페이 결제 처리가 늦어져도 결제와 주문 상태가 같게 유지되도록 개선됐어요.
  - 결제가 취소되면 주문도 결제실패로 정확하게 반영돼요.
