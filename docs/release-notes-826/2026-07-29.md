### 기능 추가
- 간편상품등록 기능 추가 (#14549)
  - 카테고리·옵션 등 주요 상품 정보를 하나의 페이지에서 빠르게 등록할 수 있는 간편상품등록 기능이 제공되어요. 기존 상품 옵션 불러오기·자주 쓰는 옵션 저장 등 편의 기능으로 상품 등록 시간을 단축할 수 있어요.
- 관리자 동시 접속 보안 강화. (#14620)
  - 관리자 계정의 중복 로그인을 제한할 수 있는 기능이 추가됐어요.
  - 보안 정책에 따라 동시 접속 허용 여부를 설정할 수 있어요.
- 상품 리스트 및 상품 가격 관리 정렬 기능 개선. (#14935)
  - 상품 리스트와 상품 가격 관리 메뉴에서 수정일 기준으로 상품을 정렬할 수 있어요.
  - 최근에 수정한 상품을 빠르게 찾아 관리 효율성이 높아졌어요.
- 고도몰 쇼핑몰 보안 강화 (#14958)
  - 웹과 모바일 웹 환경의 보안이 한층 강화됐어요.
  - 정기 보안검수 결과를 반영해 더욱 안전한 쇼핑 환경을 제공해요.
- 게시판 이미지 업로드 지원 확대. (#15037)
  - 게시판 첨부파일로 더 많은 이미지 형식을 업로드할 수 있어요.
  - 다양한 이미지 확장자가 추가로 지원돼요.
- CRM 관리 메뉴에 CRM 레시피 기능 추가 (#15041)
  - CRM 관리 메뉴 하위에 CRM 레시피 기능이 새롭게 추가되었어요.
- 사업자회원 다중 첨부 기능 반응형 스킨 지원. (#15669)
  - 사업자회원 가입 시 서류 첨부 기능이 반응형 스킨에서도 사용할 수 있어요.
  - 모바일 환경에서도 편리하게 사업자 서류를 등록할 수 있도록 개선됐어요.
- 반응형 스킨 재구매(구매했던 상품 재주문) 기능 지원 (#15694)
  - 구매했던 상품을 주문내역·주문상세에서 바로 장바구니에 담거나 구매하는 재구매 기능을 반응형 스킨에서도 사용할 수 있게 됐어요.
- 개발 담당자 온보딩 모달 및 스테이징 신청 모달 디자인 변경. (#15719)
  - 개발 담당자 온보딩 모달과 스테이징 서버 신청 프로세스의 사용자 인터페이스가 개선되었어요.
  - 변경된 디자인으로 필요한 정보를 더 명확하게 확인할 수 있어요.
- 해외구매대행 전자상거래 업체부호 설정 기능 추가 (#15930)
  - 관리자 기본설정 메뉴에서 관세청 전자상거래 업체부호를 등록할 수 있는 기능이 추가됐어요.
  - 해외구매대행 사업자가 관세청 신고를 위해 필요한 업체부호를 편리하게 관리할 수 있어요.

### 버그 수정
- 페이코 결제 보안 강화 (#14105)

  - 상품 리스트를 복사할 때 원본 상품의 이미지가 안전하게 유지돼요.
  - 복사 과정에서 발생할 수 있는 이미지 손실 문제가 해결됐어요.
- 수기주문에서 회원 장바구니 상품 2개 이상 추가 안정성 개선 (#15391)
  - 상품 결제수단이 통합설정이고 회원등급의 결제수단이 일부 제한된 경우에도, 수기주문에서 장바구니 상품을 2개 이상 선택해 추가할 수 있도록 개선되었어요.
- 공통 헤더 UI 정렬 개선 (#15532)
  - 관리자 페이지 공통 헤더의 제목과 버튼 정렬이 개선됐어요.
  - 스크롤 시 고정 헤더가 더욱 안정적으로 표시돼요.
- 스케줄러 보안 강화 (#15623)
  - 스케줄러 처리 과정의 안정성이 개선됐어요.
- 환불 처리 시 무한루프(타임아웃) 발생 개선 (#15650)
  - 예치금/마일리지가 포함된 주문 환불 시, 환불 금액에 콤마가 포함된 값이 입력되면 안분 계산이 무한루프에 빠져 타임아웃이 발생하던 문제를 개선했습니다.
- 반응형 스킨 디자인에디터 팝업 노출 개선 (#15668)
  - 반응형 스킨에서 디자인에디터로 등록한 팝업이 정상적으로 노출되도록 개선했어요.
  - 반응형 스킨은 디자인에디터 팝업 설정만 사용하도록 정리했어요.
- 반응형 스킨 상품 상세정보 본문 제목 스타일 표시 개선 (#15674)
  - 반응형 스킨에서 상품 상세정보 본문에 제목 형식으로 작성한 글씨가 정상적으로 표시되도록 개선했어요.
  - 본문 영역은 스킨 기본 스타일 초기화 대상에서 제외했어요.
- DB 데드락 자동 복구 및 발송/장바구니 교착 완화 (#15685)
  - 메일 발송·장바구니 처리 중 발생하던 DB 데드락으로 작업이 실패하던 문제를 개선했습니다.
  - 데드락 발생 시 자동 재시도하고, 잠금 순서를 통일해 교착 발생 자체를 줄였습니다.
- 모바일 상품 게시판 상세보기 조회 속도 개선 (#15695)
  - 게시글에 연결된 상품·주문 상품 정보를 한 번에 모아 조회하도록 개선해 상세보기 응답 속도가 빨라졌어요. 동시 접속이 많은 상황에서도 더 안정적으로 표시돼요.
- 비회원 주문 취소 복원 처리 개선 (#15715)
  - 비회원 주문 취소 시에도 정상적으로 복원할 수 있도록 개선됐어요.
  - 예치금과 마일리지 검증으로 인해 복원이 제한되었던 문제가 해결됐어요.
- 관리자 주문 상세보기 성능 개선 (#15798)
  - 취소 이력이 있는 주문의 상세보기 페이지 로딩 속도가 빨라졌어요.
  - 배송비 계산 처리 방식이 개선돼 페이지 응답 속도가 향상됐어요.
- 사은품 주문 보안 강화. (#15799)
  - 주문 시 사은품 수량을 임의로 변경하려는 시도를 차단하여 안정성이 향상됐어요.
  - 유효한 사은품 정보를 기준으로 검증하여 더욱 안전하게 주문할 수 있어요.
- 토스페이 결제 처리 안정성 향상 (#15857)
  - 토스페이 결제 시 알림톡이 중복 발송되거나 주문 상태가 일치하지 않던 부분이 개선됐어요.
  - 결제 완료 처리가 주문당 한 번만 실행되도록 안정성이 강화됐어요.
- 카카오 아이디 로그인 설정 페이지 헤더 표시 개선. (#15877)
  - 2024년 12월 30일 이후 설치된 상점에서 카카오 아이디 로그인 설정 페이지의 헤더가 정상적으로 표시돼요.
- 상품 판매 통계 로그 정확도 개선 (#15926)
  - 상품 판매 카운팅을 확인하는 로그 메시지가 더 정확하게 표시되도록 개선됐어요.
- 네이버 아이디 로그인 보안 강화 (#16222)
  - 네이버의 콜백 주소 검증 정책 강화에 맞춰, 네이버 아이디 로그인 시 콜백 주소를 등록된 고정 주소로 전달하도록 개선됐어요.
  - PC·모바일의 로그인·회원가입·성인인증 페이지에서 네이버 아이디 로그인이 안정적으로 동작하도록 강화됐어요.

### 기능 변경
- 디자인에디터 화면의 렌더링 일관성 및 유지보수성 개선 (#14519)
  - 디자인에디터로 제작한 화면이 에디터 화면과 실제 쇼핑몰에서 동일하게 렌더링되도록 구조가 개선되었어요. 향후 디자인 개선이 더 빠르고 안정적으로 반영될 수 있어요.
- 회원등급 평가방법 설정의 '주문금액' 표기를 '실결제금액'으로 변경 (#15489)
  - 어드민 회원등급 평가방법 설정 메뉴에서 '주문금액'으로 표기되던 문구가 실제 의미에 맞게 '실결제금액'으로 변경되었어요.
- 고도몰 관리자 팝업 표시 방식이 개선되었어요. (#15667)
  - 관리자 페이지에서 팝업이 불필요하게 반복 노출되던 현상이 개선되어 더욱 편리하게 사용할 수 있어요.
  - 팝업 노출 조건이 최적화되어 관리자 업무 효율성이 향상되었어요.
