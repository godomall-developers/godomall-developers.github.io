### 기능 추가
- 디자인 에디터 위젯 10종 추가 (#18598)
  - 디자인 에디터에서 카드, 갤러리, 롤링 배너, 타이머, 아코디언, 탭 그룹, 아이콘, 이미지 맵, 기획전 그룹, 기획전 카드 위젯을 쓸 수 있어요.
  - 새 위젯으로 꾸민 화면은 쇼핑몰 미리보기와 게시한 쇼핑몰에서 같은 모습으로 보여요.
- 디자인 에디터 슬라이드 배너 링크 기능 추가 (#18665)
  - 디자인 에디터 슬라이드 배너에서 슬라이드마다 링크를 걸 수 있게 됐어요.
  - 배경이 이미지인 슬라이드를 누르면 설정한 페이지로 이동하고, 새 탭으로 열지도 고를 수 있어요.

### 버그 수정
- 에디터 이미지 첨부 보안 강화 후속 조치 (#18821)
  - PHP 코드가 포함된 이미지는 에디터에 첨부할 수 없도록 차단하고, 관리자 에디터에도 실제 이미지 여부 검사를 추가했어요.
  - 에디터 업로드를 튜닝한 상점은 보안 강화가 적용되지 않을 수 있어요.

### 기능 변경
- 탈퇴·휴면 회원 주문 개인정보 보안 강화 (#14939)
  - 탈퇴·휴면 회원의 주문 개인정보를 일반 주문과 분리해 암호화 보관하도록 보안이 강화됐어요.
