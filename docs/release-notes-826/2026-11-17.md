### 기능 추가
- 생성형 엔진 최적화(GEO) 설정 추가 (#16234)
  - 고도몰 무료 스킨의 상품 상세에 상품 정보가 자동으로 제공되고 llms.txt 제공과 AI 로봇 허용이 함께 적용돼요. 스킨에 상품 정보를 직접 넣어 둔 상점은 설정을 확인해 주세요.
- 자동 알림 정책 보안 강화 (#17606)
  - KISA 보안 가이드에 맞게 자동 알림 정책이 개선됐어요.
- SMS 발송 세팅 현황 안내 블록 삭제 (#18091)
  - 문자사업자 SMS 발송 세팅의 책임자 등록·소유권 재인증·사용함 설정 현황을 한눈에 확인할 수 있는 안내 블록이 삭제됐어요.
- 쇼핑몰 프런트 WebMCP 도구 제공 (#18126)
  - AI 에이전트가 상품 조회, 장바구니 관리, 주문, 쿠폰 조회 등의 작업을 수행할 수 있는 WebMCP 도구가 추가됐어요. 쇼핑몰의 주요 기능을 AI 기반으로 자동화할 수 있어요.

### 버그 수정
- 에디터 이미지 첨부 보안 강화 (#18283)
  - 에디터에서 SVG 파일 첨부를 차단하고, 쇼핑몰 글쓰기 화면을 거치지 않은 이미지 업로드를 차단했어요.
  - 게시판 글쓰기나 에디터 업로드를 튜닝한 상점은 이미지 첨부가 되지 않거나 보안 강화가 적용되지 않을 수 있어요.
- 갤럭시아머니트리 면세 상품 결제 처리 개선 (#18288)
  - 면세 상품을 결제하면 면세금액이 PG사에 함께 전달되어 매출전표에 면세로 표시돼요.
  - 부분취소할 때도 과세·면세 금액을 나눠 처리해요.
- CRM 발송자 수 처리 안정성 개선 (#18402)
  - CRM 발송자 수 집계 로직이 개선됐어요. 정확한 발송자 정보를 제공하도록 처리되었어요.
- 상품 상세페이지 플러스리뷰 평점 표시 안정성 개선 (#18795)
  - 플러스리뷰 평점이 소수점인 경우 상품 상세페이지가 정상 표시되도록 개선됐어요.
