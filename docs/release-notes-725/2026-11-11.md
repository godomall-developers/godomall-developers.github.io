### 기능 추가
- 주문 적용 쿠폰 회원 다운로드 발급 방식 추가 (#15856)
  - 주문 적용 쿠폰도 회원이 쿠폰존·상품상세에서 직접 받아 주문서에서 사용할 수 있도록 회원 다운로드 발급 방식이 추가됐어요.
- 14세 이상 연령 동의 항목 추가 (#17190)
  - 회원가입 및 인증 절차에서 14세 이상 연령 동의 항목이 추가됐어요.
- 쿠폰 웹훅 기능 추가 (#17494)
  - 쿠폰 관련 이벤트를 외부 시스템으로 전달할 수 있는 웹훅 기능이 추가됐어요.
- SMS 발송 세팅 현황 안내 추가 (#18091)
  - SMS 설정 화면 상단에서 발신관리책임자 등록, 발신번호 소유권 재인증 및 신규 등록, 발신번호 사용함 설정의 완료 여부를 확인할 수 있어요.

### 버그 수정
- 카카오 회원 가입 팝업 처리 개선 (#13002)
  - 인트로 페이지에서 카카오 회원 가입 시도 시 올바른 로그인 팝업이 표시되도록 개선됐어요.
- 최신 iOS Safari 환경 네이버페이(주문형) 이동 안정성 개선 (#15890)
  - 최신 iOS Safari에서도 네이버페이(주문형) 주문 페이지로 안정적으로 이동해요.
  - 광고 성과 측정(페이스북 픽셀)은 기존과 동일하게 유지돼요.
- 예치금·마일리지 포함 주문 환불 처리 안정성 개선 (#16648)
  - 예치금·마일리지가 포함된 주문도 환불이 지연 없이 처리돼요.
  - 환불 금액 안분 계산 방식이 개선됐어요.
- 배송지 수정 기능 보안 강화 (#16848)
  - 배송지 수정 시 입력값에 대한 XSS 검증이 강화됐어요. 보안성이 개선되었습니다.
- 주문 메뉴 개인정보 접속기록 미적재 및 엑셀 다운로드 처리건수 오류 수정 (#16969)
  - 주문 메뉴의 개인정보 접속기록이 정상 적재되도록 개선됐어요. 엑셀 다운로드 처리건수 집계 방식도 정상화됐어요.
- 해외몰 구글 로그인 콜백 URL 경로 처리 개선 (#16971)
  - 해외몰에서 추가도메인 사용 시 구글 로그인 콜백 URL의 경로 처리가 개선됐어요. 인증 프로세스의 정확성이 강화됐습니다.
- 휴대폰 결제 데이터 처리 안정성 개선 (#17008)
  - 휴대폰 결제 응답 데이터가 원본 그대로 처리되도록 개선됐어요.
- 공급사 계정 다른상품교환 처리 개선 (#17060)
  - 공급사 계정에서도 다른상품교환이 정상적으로 처리돼요.
- 이지페이 결제완료 처리 안정성 개선 (#17064)
  - 이지페이 결제완료 페이지가 더 안정적으로 동작하도록 개선됐어요.
- 플러스리뷰 중복 작성 제한 정확도 개선 (#17111)
  - 미승인 리뷰 노출 설정을 사용하는 쇼핑몰에서도 중복 작성 제한이 정확하게 적용돼요.
- 네이버 판매지수 집계 정확도 개선 (#17127)
  - 상품별 판매지수가 더 정확하게 집계돼요.
- 상품 수정시 정가/매입가/판매가 입력 안정성 개선 (#17237)
  - 상품 수정 시 가격에 콤마가 포함될 경우 입력이 정상 처리되도록 개선됐어요.
- 가상계좌 입금취소 처리 정확도 개선 (#17272)
  - 은행에서 가상계좌 입금이 취소되면 주문 상태에도 정확하게 반영돼요.
- 현금영수증 목록 발급금액 변경 표시 정확도 개선 (#17281)
  - 현금영수증 목록에서 발급금액 변경 표시 정확도가 개선됐어요.
- 상품 엑셀 업로드 시 단위가격 반영 개선 (#17350)
  - 엑셀 업로드 시 판매가가 미입력된 경우, 기존 판매가를 기준으로 단위가격이 반영되도록 개선됐어요.
- 엑셀 다운로드 시 자체상품코드 텍스트 서식 적용 (#17351)
  - 엑셀 다운로드 시 자체상품코드를 텍스트 서식으로 처리하여 앞의 0이 누락되지 않도록 개선했어요.
- 판매채널/설정 메뉴 안내 링크 변경 (#17803)
  - 판매채널 및 설정 메뉴의 안내 링크를 업데이트했어요.
- 토스페이 카드 승인 거절 건이 결제시도로 남는 문제 개선 (#18100)
  - 토스페이 결제 시 카드 승인이 거절(잔고부족·한도초과 등)된 주문이 '결제시도' 상태로 남던 문제를 개선했어요.
  - 거절된 주문은 '결제실패'로 처리되고, 주문완료 화면에서 거절 사유를 확인할 수 있어요.

### 기능 변경
- 엑셀 다운로드 성능 개선 및 통계 기록 확대 (#16808)
  - 엑셀 다운로드 시 불필요한 요청을 최적화하고, 더 많은 다운로드 타입에 대해 기록되도록 개선했어요.
- 로그인·카카오싱크 보안 강화. (#16883)
  - 로그인 정보가 별도 암호화 없이 HTTPS 보안 연결로 전달되도록 전송 방식이 변경됐어요.
  - 스킨을 갱신하지 않은 상점도 기존과 같이 이용할 수 있어요.
- 보안서버 HTTPS 리다이렉트 처리 개선 (#16919)
  - 보안서버의 HTTP에서 HTTPS로의 리다이렉트 처리 방식을 임시 리다이렉트(307)에서 영구 리다이렉트(308)로 변경했어요. 브라우저와 클라이언트의 캐싱 처리를 개선하여 안정성을 높였어요.
- SMS 발송담당자 지정 인원 제한 해제 (#18250)
  - 운영자 권한 설정에서 SMS 발송담당자를 인원 제한 없이 지정할 수 있어요.
  - 기존에는 최대 5명까지만 지정할 수 있었어요.
