### 기능 추가
- 게시판 스팸방지 히든 필드 추가 (#15952)
  - 게시판 스팸방지 기능을 강화하기 위해 히든 필드를 추가했어요.
- 고도몰 CRM OR 행동조건 도입 (#16090)
  - 고도몰 CRM 기능에 OR 행동조건을 추가할 수 있어요.
- 네이버쇼핑 상품평 평점 컬럼 추가 (#16768)
  - 네이버쇼핑 상품 정보에 상품평 평점을 추가했어요. 더욱 상세한 상품 정보 관리가 가능해졌어요.
- 개발소스관리 커스터마이징 현황 환경 안내 띠배너 추가 (#16899)
  - 커스터마이징 현황 진입 화면 상단에 운영/스테이징 환경 안내 띠배너가 추가됐어요. 닫기 및 다시 보지 않기 기능을 제공합니다.
- 재입고 알림 신청 보안 강화 (#16905)
  - 재입고 알림 신청 시 수집되는 개인정보가 파기되도록 개선됐어요.

### 버그 수정
- 공급사 관리자 상품 리스트 선택복사 및 노출/판매 수정 기능 안정성 향상 (#15376)
  - 공급사 관리자 계정에서 상품 리스트의 선택복사 및 노출/판매 수정 기능이 안정적으로 동작하도록 개선됐어요.
- 웹FTP 파일 목록 파일명 보안 강화 (#16311)
  - 웹FTP 파일 목록에서 파일명의 보안 취약점을 개선했어요. 안정성이 강화됐어요.
- 관리자 답변 게시글 보안 강화 (#16313)
  - 관리자 답변 게시글 저장 시 XSS 공격으로부터 보호하기 위해 필터를 강화했어요.
- 보안 강화 (#16336)
  - 외부 공격 시도에 대한 영향도를 검토하고 보안을 강화했어요.
- zip 압축·파일 처리 보안 강화 (#16339)
  - zip 압축과 파일 복사·삭제·병합을 외부 프로그램 호출 없이 처리하도록 개선해 보안이 강화됐어요.
  - 기존 동작에는 영향이 없어요.
- 환불완료 주문 상태 정합성 개선 (#16342)
  - 관리자가 주문을 일괄로 상태변경할 때, 다른 경로에서 환불완료된 주문의 상태가 함께 바뀌지 않도록 개선됐어요.
- 엑셀·CSV 다운로드 및 쿠폰 발급 보안 강화 (#16347)
  - 엑셀·CSV 다운로드의 압축 비밀번호와 쿠폰 발급 기능의 보안을 강화했어요. 공백과 특수문자를 포함한 비밀번호와 경로가 안정적으로 처리돼요.
- 주문·SMS 처리 안정성 개선 (#16402)
  - 여러 고객이 동시에 주문 취소·교환 또는 SMS 발송을 처리할 때의 안정성을 강화했어요. 기존 기능·화면·속도 변화 없이 내부 처리 방식만 개선됐어요.
- 로그아웃 페이지 보안 강화 (#16683)
  - 로그아웃 안내창의 이동 주소 표시에 이스케이프를 적용해 반사형 XSS를 차단했어요. 정상 페이지 이동 동작에는 영향이 없어요.
- 아이디찾기 보안 강화 (#16738)
  - 아이디찾기 기능의 보안이 강화됐어요. 화이트리스트 검증을 통해 안정성을 높였으며, 정상 이용에는 영향이 없어요.
- 상품 복사 시 이미지 폴더 구조 처리 개선 (#16751)
  - 상품 복사 시 원본 상품의 이미지 폴더 내 하위 폴더 구조가 정상적으로 복사되도록 개선됐어요.
- 상품 상세페이지 이미지 업로드 안정성 개선 (#16766)
  - 상품 상세페이지 이미지 업로드 안정성이 개선됐어요.
- 개발 작업소스 운영 적용 프로세스 안정성 개선 (#16767)
  - 개발 작업소스 보기에서 검증을 통과한 항목이 운영소스에 정상 적용되도록 개선됐어요.
- KCP 정기결제 무기명 법인카드 등록 기능 개선 (#16778)
  - KCP 정기결제 카드 등록 시 무기명 법인카드도 정상적으로 등록할 수 있도록 개선됐어요.
- 카카오페이 결제 노티 중복 처리 방지 (#16817)
  - 카카오페이 결제 노티가 짧은 간격으로 중복 수신되어도 재고와 결제 상태가 한 번만 정확하게 반영되도록 개선됐어요.
  - 동일 주문에 대해서는 노티가 여러 번 와도 한 번만 처리되도록 안정성이 강화됐어요.
- 관리자 SEO 페이지 로드 안정성 개선 (#16822)
  - 관리자 SEO 페이지 로드 시 발생하는 데이터 처리 문제를 개선했어요.
- 결혼여부 기본값 저장 안정성 개선 (#16831)
  - 결혼여부 필드의 기본값이 올바르게 저장되도록 개선됐어요.
- 특정 회원등급 할인 가격 적용 개선 (#16853)
  - 특정 회원등급에 정액할인을 적용할 때 가격에 콤마가 포함된 경우 정상적으로 등록되지 않던 문제를 개선했어요.
- 회원등급 평가 처리 개선 (#16924)
  - 회원등급 평가 프로세스의 안정성이 개선됐어요.
- 주문완료 애널리틱스 수집 시각 정확화 (#17142)
  - 주문 완료 애널리틱스 수집 시각을 결제 시각으로 고정하여 데이터 정확성이 개선됐어요.
