### 기능 추가

  - 애널리틱스 세션 기반 분석의 데이터 수집 방식이 개선되고 새로운 분석 지표가 추가됐어요.
  - 더 정확하고 다양한 쇼핑몰 이용 패턴을 파악할 수 있게 됐어요.
- 개인정보 수집 및 이용 동의 템플릿 개정 (#15615)
  - 개인정보보호법 준수를 위해 어드민 개인정보 수집 및 이용 동의 템플릿을 개정했어요.
- 지역별 추가배송비 구간별 반복 부과 옵션 추가 (#15621)
  - 제주·도서산간 등 지역별 추가배송비를 동일 상품 수량/무게 구간만큼 반복 부과(×N)할 수 있어요. 기존 등록 상점은 '1회 부과'로 자동 유지되어 배송비 동작 변화가 없습니다.
- - [게시판] 비회원 글쓰기 보안 강화 (#15949)
  - - 비회원이 게시판에 글을 짧은 시간 안에 연속으로 등록하지 못하도록 제한해 무분별한 자동 등록에 대한 방어가 강화됐어요.
- LMS 메시지 발송 시 제목 입력 기능 (#16103)
  - 회원 개별/전체 SMS 발송, 장바구니 알림, 컴백쿠폰의 LMS 발송 시 제목을 입력할 수 있어요. 광고성 발송 시 본문과 제목 모두에 (광고)가 표기돼요.
