### 버그 수정
- WebFTP 보안 강화 (#16535)
  - WebFTP에서 파일 경로 검증 보안 기능이 강화됐어요.
- 세션 SameSite 판단 성능 개선 (#17028)
  - 세션 SameSite 속성 판단 시 불필요한 중복 조회를 제거하여 데이터베이스 쿼리 성능을 개선했어요.
- 쿼리 디버그 정보 수집 최적화 (#17029)
  - 데이터베이스 쿼리 실행 시 디버그 정보 수집 방식을 최적화해 성능을 개선했어요.
- 모바일 기기 판별 성능 최적화 (#17030)
  - 기기 판별 캐시 확인 순서를 개선해 불필요한 연산을 제거했어요.
- 자동 배송완료/구매확정 스케줄러 성능 최적화 (#17406)
  - 자동 배송완료/구매확정 스케줄러의 메모리 사용량을 개선했어요.

### 기능 변경
- 통계 > 주문 분석 도움말에 5년 이전 주문 구매자수 안내 문구 추가 (#17308)
  - 통계 > 주문 분석의 주문통계·연령별·지역별·성별 주문통계 도움말에 5년 이전 주문의 구매자수 안내 문구가 추가돼요. 개인정보 보관 기간이 지난 주문은 구매자수가 실제 건수와 관계없이 1 또는 0으로 표시돼요.
