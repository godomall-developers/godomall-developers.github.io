### 기능 추가
- PAYCO 복합결제(카드+포인트) 지원 (#15408)
  - PAYCO 결제 시 카드와 포인트를 함께 사용하는 복합결제를 이용할 수 있어요. 승인/취소 응답에 카드·포인트 결제 결과가 함께 포함되어도 정상 처리되어요.

### 버그 수정
- 네이버 아이디 로그인 차단 현상 수정 (네이버 CallbackURL 검증 강화 대응) (#15726)
  - 네이버의 OAuth CallbackURL 검증 강화(strict match)로 발생한 네이버 아이디 로그인 불가 현상을 수정합니다.
  - redirect_uri를 등록값과 동일한 고정 URL로 전송하고, 동적값(referer/returnUrl)은 state 파라미터로 이관했습니다.

### 기능 변경
- 회원가입, 게시판 보안 강화 (#15943)
  - 회원가입, 게시판과 플러스리뷰의 스팸 차단 기능이 강화됐어요.
  - 자동화된 스팸 게시글을 더욱 효과적으로 차단할 수 있어요.
